# 🧠 Second Brain: Computer Vision with Gemini Notebook

## Overview
A curated digital "Second Brain" built with **Google NotebookLM (Gemini)** and grounded in high-authority academic sources. This project demonstrates how Retrieval-Augmented Generation (RAG) and structured prompt guidelines can be used to synthesize complex Computer Vision concepts, generate concept maps, and produce strictly cited technical summaries.

## Indexed Sources & Reliability
1. **Stanford CS231N: Deep Learning for Computer Vision (Video Lectures):** Indexed for foundational academic rigor from a globally recognized institution.
2. **Academic Slides & Reference PDFs:** Supplementary technical materials selected for peer-reviewed accuracy.

## System Persona & Prompt Guideline
* **Instruction:** *"Act as an expert professor in Computer Vision, explaining complex concepts clearly with strict adherence to the indexed sources."*

## Key Inquiries & Synthesized Outputs

### 1. Fundamentals & Modern Applications of Computer Vision
* **Prompt Strategy:** Requested an accessible, structured explanation of core Computer Vision concepts for beginners.
* **Key Takeaways Covered:**
  * **The Semantic Gap:** How machines interpret images as RGB numerical matrices versus human visual perception, addressing challenges like occlusion, lighting, and viewpoint variation.
  * **Core Tasks:** Image Classification, Object Detection (bounding boxes), and pixel-level Segmentation.
  * **Technical Evolution:** Progression from manual feature extraction to Convolutional Neural Networks (CNNs), Vision Transformers (ViTs), and Self-Supervised Learning.
  * **Real-World Applications:** Medical imaging diagnostics, autonomous vehicles, Vision-Language Models (VLMs), video understanding, and 3D reconstruction.

### 2. Neural Network Architectures for Brain Tumor Detection
* **Prompt Strategy:** Requested a technical synthesis of state-of-the-art architectures used in medical MRI analysis.
* **Key Takeaways Covered:**
  * **CNNs & Transfer Learning:** ResNet, DenseNet201, GoogLeNet, and lightweight variants (MBINet) for MRI classification.
  * **U-Net Family:** Encoder-decoder architectures with skip connections (e.g., BraTS-UMamba) for precise pixel-level tumor segmentation.
  * **Vision Transformers (ViTs) & Hybrid Models:** CNN-Transformer hybrids and Graph Neural Networks (LG-GNN) for capturing long-range contextual features.
  * **Frontier Models:** State Space Models (Mamba), Diffusion models for data augmentation (D3M), and specialized genomic Foundation Models (FoundBioNet).
